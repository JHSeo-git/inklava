# Inklava · 잉클라바

Mermaid 문법을 입력하면 [Pele](https://pele.run/)로 다이어그램을 렌더링하는 간단한 웹 앱을 만들기 위한 프로젝트입니다.

이름은 Ink와 Lava를 합친 말로, 입력한 글이 다이어그램으로 흐르고 굳어지는 모습을 담았습니다.

## 구상

Mermaid 소스를 입력하는 편집 영역과 SVG 다이어그램을 확인하는 미리보기 영역을 제공합니다.

## 현재 상태

프로젝트 준비 단계입니다. 로컬 Git 저장소와 README, MIT 라이선스만 만들었으며, 앱 구현과 개발 환경 구성은 아직 시작하지 않았습니다.
